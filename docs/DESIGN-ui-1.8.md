# v1.8 连线交互：先看一条，再决定带走什么

用户批准连线预览后落地。本版沿用 v1.7 的控制台、卡片和草稿确认流程，重点解决连线过密、分叉范围含糊、查看与选取混在一起的问题。

## 三种关系分开看

| 当前操作 | 主画面 | 不表达什么 |
| --- | --- | --- |
| 浏览整理路径 | 圆角正交实线，共用前缀只画一次；当前路径高亮 | 不是历史执行顺序或模型隐藏思考 |
| 在卡片中展开一条关联 | 路径淡出，只画当前关联；从卡片外侧绕行 | AI 关联不是已证实因果；共同引用不是依赖 |
| 打开一份派生草稿 | 路径淡出，仅该草稿的材料来源汇集到下方来源线 | 汇集线不是执行链，也不追踪后续会话 |

关联与来源不能同时展开。旧报告没有显式路径时保留卡片和按需关联，不用关联线伪造整链。

## 路径线的交互

- 悬停：暂时突出到当前连接的上游路径及两端。离开恢复浏览路径。
- 点击：锁定这条连接，下方打开连接详情；随后悬停其他线不抢走锁定。
- 共用段：明确显示被多少条路径共用，不自动换到任意分支。
- 分叉点：先列出各方向，用户点方向后再看该连接。公共干线与各分支尾段使用不重叠的命中区域。
- 单后继：干线仍直接打开连接，不显示虚假的“一方向分叉”。
- 取消锁定或 Escape：结束查看，保留已选节点、排除项、任务和目标项目。

线有加宽命中区域和固定尺寸的键盘按钮；鼠标划过时不改变按钮宽度。拖动空白处用于平移，点线或控件不触发拖动。

## 连接详情中的明确动作

“两端原文”并列显示端点实际引用的保存片段、事件号和字符范围，缺引用时明示。原文中的任意文字只作文本渲染。查看原文不调用模型，也不自动选材。

“选入两端（2项）”只追加端点摘要；“从起点选到 Nxx（N项）”追加该实例的完整前缀。两者都保留已有材料，并尊重“本次不带走”及逐段排除原文。按钮旁预告真正新增的摘要数、原文数及跳过项；路径范围数不冒充实际新增数。重复摘要导出一次，分支位置单独记录。

关联端点若在不同分支中重复出现，只使用当前明确查看的实例或唯一实例；仍有歧义就列出前缀让用户定位。位置确定前不画猜测连线、不允许从该关系直接选入两端。共同引用保持无方向；AI 关系以原始 from/to 解释。

“关系自身依据”单列关系的引用，不能用两端卡片的引用代替；缺失引用明示。关系专属原文不会因为选入两端而自动进入草稿，需要用户单独选入。

## 派生来源

派生草稿放在材料区下方。默认不铺开所有快照的回连；打开一份时，读取快照保存的实例，并通过列间空隙向下汇集。同列公共段去重，连线不能穿过卡片。

没有实例、实例已不存在或实例不属于所选材料时不猜测位置；详情列出无法定位的摘要。来源清单保留全部选中摘要和有效原文入口，完整草稿仍以当次保存的 prompt 为准。仅选原文的快照也可查看，不能虚构摘要节点来源。

## 实现边界

连线几何、命中区和状态切换全部在客户端完成，没有新增 DSH 接口、图形依赖、模型调用或持久化格式。路径成员关系按完整前缀计算，不能根据“同一张卡片”猜分支。

新会话仍经过完整草稿预览与明确确认；成功后只预填或复制。布局变化不触碰项目文件、原始会话或 memory。派生快照仍仅存本浏览器；容量和失败语义与 v1.7 相同。

验证记录见 [REVIEW-1.8](REVIEW-1.8.md)。超长图需要平移、缩放；画布本身可滚动，页面外层不应横向溢出。完整键盘阅读替代、原生桌面高 DPI 和真实模型质量仍属后续验收范围。
