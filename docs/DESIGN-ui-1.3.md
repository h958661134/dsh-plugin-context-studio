# v1.3 模块化 Inspector UI

本次客户端实现按 `.tmp/context-api-spec.md` 及协作中的协议补充完成。只改 `lib/client.js`、客户端测试及本文件；后端、README、发布及真实浏览器验收由主代理负责。本分工未操作桌面、浏览器、API key 或其他插件目录，也未创建提交。

## 用户路径

1. **选会话、定位回答。** 顶部会话下拉和左侧目录都来自独立 `/sessions`，不等待 Inspector。回答显示紧凑预览，原文需主动打开；可选相邻回答、最早/最新回答。输出目录有窗口时增加整组跳转，少量回答保持单行导航。
2. **按来源核对。** 用户要求、项目约定、引用会话、工具结果、历史回答、技能是主要模块，系统与环境、其他上下文默认收起。无记录的主要模块放入弱化的折叠目录。卡片点击后收拢模块目录，显示选择状态，并将焦点和视口移到记录区；“更换模块”可重新展开。
3. **按页或选文字加入草稿。** 记录按后端页码读取，点击后打开非模态原文抽屉。正文和调用参数分别分页，可加入本页，也可加入选中文字。草稿继续使用已有预览、确认启动会话和写入指令的安全流程，不自动发送。

状态名称使用“在输入中 / 已被替换 / 位置未知”。`active` 只说明当时的消息位置，不能证明内容正确或有效。卡片的大数字对应当前状态；已替换、位置未知和线索仅在有数量时辅助显示。

## 容量和协议约定

- 新 Inspector 只请求 `/inspect-view` 与 `/inspect-detail`，不调用旧 `/inspect`。
- 列表不包含完整正文，原文按最多 12,000 个 JavaScript 字符单位逐页读取。分页与导航窗口本身不显示成内容缺失；原文异常只按 `incomplete/notices` 提示。
- 搜索明确标注“搜索标题或预览（非全文）”，输入最长 200 字符，不暗示全文搜索。
- 使用 `previousSeq/nextSeq`、`firstSeq/lastSeq`、`earlierWindowSeq/laterWindowSeq` 导航，不从局部下拉项猜测全局序号。序号 0 合法。
- `summary.available=false` 时隐藏模块计数和记录列表，明确提示数量未知，保留回答导航、回答原文及警告。不会显示误导性的“0 上下文”。
- 尚无 assistant 回答时，`boundary` 是上下文截止点，不是回答序号；切模块、状态、分页及读原文全部省略 `answer`。已有回答时锁定其 seq，后续翻页不会自动跳到最新回答。
- `timeline.interrupted`、`answer.issues` 的问题线索由后端统一进入 `warnings`；客户端展示这些线索，不另调旧接口。
- 白名单 `tool/call` 详情的 `status=source` 标为“来源记录”，不将辅助来源误标为回答输入；其他不可查看的关联由后端拒绝，在抽屉中显示读取错误。

## 请求与来源准确性

模块、状态、回答、记录页、原文页、正文/参数和会话切换均有各自的请求身份。旧请求被取消；即使底层忽略取消并迟到，也不能写入当前视图。JSON 读取挂起也可通过取消结算并清除超时定时器。

原文详情失败只影响抽屉，可单独重试。目录分页失败保留已有回答导航，避免用户只能刷新整个插件。手动重试目录会发一次 `refresh=1`，随后翻页不持续刷新缓存。

选中文字使用 textarea 的实际选择范围，不再用 `indexOf` 猜测同文的位置。加入草稿的键包含会话 ID、事件 seq、`body/arguments` 和绝对起止偏移；草稿保留 `sourcePart/textOffset`、`evidencePart/evidenceOffset/evidenceEnd`，人可读来源也包含原文类型与字符范围。不同页、正文与参数、不同会话不撞键；同一范围快速重复点击不会重复加入。旧草稿保持可读，不做自动迁移或覆盖。

## 首屏与可访问性

根据主代理提供的 1440×900 实测反馈，压缩顶部、页签、会话选择、标题及导航间距；回答预览限制两行。主要模块卡片约 100px 高，Inspector 中心区域宽度达到 800px 时三列，较窄时两列，最窄时单列。卡片提供明确“查看记录”入口，系统背景默认折叠。实际首屏是否完整仍需主代理在 DSH 的侧栏宽度和缩放设置下截图验证。

模块按钮支持原生键盘激活和 `aria-pressed`，切模块将焦点移到记录区；原文抽屉非模态，打开后聚焦，可按 Escape 关闭，原触发按钮仍存在时恢复焦点。现有修改确认 Dialog 独立保留。

## 验证与边界

客户端 VM 测试保留原有 8 个场景，新增 20 个场景：模块入口反馈、空模块弱化、状态迟到防护、回答窗口导航、记录分页搜索、容量不可用但可导航、无回答会话、原文分页与重复文字定位、参数来源、详情取消和重试、目录重试、跨会话取消、草稿来源持久化与去重、独立目录、JSON 挂起取消、Escape、少量回答导航、只读来源标签，以及使用真实新后端函数的长消息尾页摘录契约测试。

`node --check lib/client.js` 通过；`node --test tests/client.test.mjs tests/client-modules.test.mjs` 结果为 **28/28 通过**。VM 断言覆盖交互状态、请求和来源，不证明真实浏览器布局、焦点表现或宿主兼容性；这些由主代理在隔离 4001 验收。主代理已反馈紧凑版在 1440×900 首屏可看到全部主要模块，本分工未自行操作浏览器确认。

当前无阻塞协议问题。无回答会话通过省略 `answer` 使用宿主当前上下文；若宿主同时继续写入会话，该上下文自然可能变化。附件仅按后端可见文本表示处理，不推断模型内部注意力、推理过程或最终供应商请求。
