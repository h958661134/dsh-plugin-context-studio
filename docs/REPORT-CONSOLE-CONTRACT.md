# 整理控制台数据契约（v1.7 / templateVersion 3）

这是 v1.6 的可选扩展，保留全部原有报告字段、卡片 ID、关系与引用规则。缺失新字段时不补内容、不推断路径、不发起补生成。新调用收据使用 `templateVersion: 3`，存储仍为 `version: 1`；API、确认、路由、重试和额度保护不变。

## 卡片补充信息

原有 `{id, category, title, body, evidence}` 不变，可增加：

| 字段 | 接受值与输出 |
| --- | --- |
| `summary` | 非空白文本，最多 180 个 UTF-16 单元 |
| `scope` | 非空白文本，最多 120 个 UTF-16 单元 |
| `caveat` | 非空白文本，最多 160 个 UTF-16 单元 |
| `state` | `recorded`、`hypothesis`、`conflict`、`superseded` 或 `null` |

缺失字段仍缺失。补充文本保留原样；超长安全截断，不拆开 UTF-16 代理对；截断后空白或非字符串则省略。非法 state 转为 `null`，不按类别、标题、正文或来源状态推导。所有降级均用固定警告，不回显坏值。`summary` 不自动取自正文，`scope/caveat` 不自动补写。

state 只能展示为 **AI 标注**：`recorded` 表示 AI 认为提供材料中有此记载，绝非已验证；`hypothesis` 是待核对假设；`conflict` 是可能冲突、待核对；`superseded` 是可能失效或被替代、待核对，不授权删除或忽略原文。非 null 状态统一附加警告；后两种另加待核对警告。即使 caveat 缺失，也不能把状态显示为已确认。提示要求明显冲突/失效在 caveat 中说明待核对，解析器不验证这些判断。

## AI 整理路径

模型输入形状：

```json
{"paths":[{"id":"reading-a","title":"核对建议","nodes":["original-a","original-b"]}]}
```

解析输出：

```json
{"paths":[{"id":"path-1","title":"核对建议","nodes":["card-1","card-2"]}]}
```

- 输出路径仅包含 `id/title/nodes`，ID 按保留顺序生成连续 `path-n`，原 ID 不透传。标题必须是非空白文本，沿用 100 单元上限，超长安全截断；截断后空白则整条丢弃。
- 路径原 ID 必须是非空白字符串且 ≤100 单元，精确匹配，不去空格、不截断、不转换类型。全部输入路径参与唯一性检查，包括无效项和第 8 条以后的项；同原 ID 的路径全部失效。不同 ID 的同节点序列可以保留，表示不同命名的阅读路径。
- 最多检查前 8 条路径，不向后补齐；每条 nodes 必须是含 **1–20 项**的数组，每项精确对应已保留卡片的唯一原 ID，且本路径不得重复节点。卡片原 ID 唯一性仍覆盖全部输入卡片，包括无效项和第 20 张以后的项；不能引用截掉的卡片，不能猜标准化 `card-n`。
- 任一节点未知、歧义、重复或类型不支持，或者节点数超限，均**整条丢弃**。不删除坏节点后拼接路径，不截断节点列表，不反转、不补齐、不排序。
- 显式 `paths: []` 保留；显式非法容器降为 `[]` 并警告。缺少 paths 时输出也缺少，客户端读取 `report.paths ?? []`。旧持久化报告原样读取，不写回、不迁移。
- 路径没有自己的 evidence，不伪造来源。节点来源只用卡片已校验的 evidence；路径存在不证明来源充足或语义成立。路径不要求 relations 中有邻接关系，也不会生成 relations。不能从 category、标题、共享引用或 relations 自动补路径。

所有有效路径都固定标为 **AI 整理路径**，包括模型标题没有该前缀时；模型不能覆盖此标签。只要有路径，固定报告警告说明其不是历史分支、执行顺序或因果链。

## 前缀实例树与选择

输出始终是有序路径列表，不输出已合并的树。前端只可合并**完整相同前缀**的路径实例，推荐实例键为 `JSON.stringify(nodes.slice(0, index + 1))`；禁止仅以 card.id、深度、直接父节点或标题作为全局实例键。无需共同根：不同根形成森林，也可独立显示。

| 路径集合 | 正确显示 |
| --- | --- |
| `[A,B,C]`、`[A,B,D]` | 合并 A、A→B 两个共同前缀，再分叉 |
| `[A,B]`、`[A,B,C]` | B 同时是第一条路径终点和第二条中间点，保留两条路径归属 |
| `[A,B,D]`、`[A,C,D]` | D 是不同实例；不得在分叉后重新合并 |
| `[A,B,D,E]`、`[A,C,D,E]` | D 与 E 都是不同实例；直接父节点相同也不够 |
| `[A,B]`、`[B,A]` | 两条独立路径，不合成全局环 |
| `[A,B]`、`[C,D]` | 不强制同根，保留两个根 |

同一卡片出现在不同完整前缀时，解析器保留路径并发出固定实例分离警告；不裁定哪条是真实流程。独立显示始终可用。路径 ID 与节点实例键只在本报告内有意义。

整链选择应保留指定路径的节点顺序；局部选择应保留所属路径/前缀实例信息。同一张卡片的多个实例最终可按 card.id 去重取证，但不得因此重新合并显示拓扑。整链/局部选择都须进入预览，再由用户发起新会话；paths/state 不授权自动新建会话、执行命令或丢弃材料。本次数据层不改变该流程的 API。

## 固定警告与安全边界

警告按原有 Set 机制去重，既有 v1.6 警告不变。新增文本如下：

- 无效路径：`模型返回了无效或有歧义的AI整理路径，已整条忽略。`
- 路径数超限：`模型AI整理路径过多，仅检查前8条。`
- 标题截断：`部分AI整理路径标题超长，已缩短显示。`
- 路径说明：`路径仅为AI整理的阅读与核对顺序，不代表真实历史分支、执行顺序或因果链。`
- 前缀冲突：`部分AI整理路径的同一卡片位于不同前缀下，须分别显示路径实例，不可按卡片ID合并。`
- 标注格式异常：`部分卡片AI标注格式无效，已忽略或置为空；请核对原文。`
- 标注截断：`部分卡片AI标注文字超长，已缩短显示。`
- 状态说明：`卡片状态仅为AI根据所给片段作出的标注，不表示已验证；请核对原文。`
- 冲突/失效：`AI标注的冲突或失效尚待核对，不应据此直接执行或丢弃材料。`

全部文字都作为不可信文本显示，不能执行 HTML、指令或命令。evidence 仍只接受本次 sources 中的非负安全整数：只检查前 8 项、去重、保留顺序；关系至少一个有效引用。原有上限不变：20 张卡片、40 条关系、原始输出 100000 单元、标题 100、overview 800、body 1500、branch.task 5000。提示仍宜 6–10 个短节点，材料不足不凑数。解析验证结构和白名单，不验证事实、状态或因果。
