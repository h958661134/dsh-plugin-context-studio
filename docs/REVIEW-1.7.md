# v1.7 工程校验：分支控制台

日期：2026-11-16。本地版本1.7.0，未推送、未发布。

## 范围与验收方法

用户先批准控制台及卡片设计，再批准整链/局部选择、原文核对、预览后创建草稿的流程。本版据此实现 Git 风格的材料分支图，保留原始记录检查。路径表示 AI 整理，不冒充原生历史分叉或隐藏推理。

三个协作代理分别负责报告契约及数据层测试、客户端独立回归、设计与安全复核；主代理整合实现、复核差异、运行全量并测试真实浏览器。审查记录只覆盖已查范围，不声称找到了所有不足。

`node --test tests/*.test.mjs`：**392通过，0失败、0取消、0跳过、0TODO**。相对v1.6新增50项：数据层29项、客户端21项，旧交互测试随新流程调整。

新增数据层测试覆盖可选字段、状态白名单、UTF-16截断、重复/歧义原ID、超限引用、整条路径丢弃、不同前缀实例和旧报告兼容。客户端测试覆盖整链与旁支、局部实例、缺项提示、来源排除、草稿边界、存储失败和确认失效。

两轮独立复核发现并修复的六项 P2：

1. **局部选择丢失分支位置**：选择保存完整前缀实例，浏览另一条路径不改变缺项依据。
2. **导出丢失适用范围与风险**：草稿保留scope/caveat/state，明确为AI标注，不能把“待验证”变成事实。
3. **旧报告共享引用线丢失**：兼容图保留实际共同引用点线，与AI关系长虚线区分。
4. **派生图误画单一来源**：对全部选中实例分别画来源线，详情用列表分隔，不把任意选材串成不存在的路径。
5. **补选未保存实例**：补选缺项同时记录对应前缀；再次移除根节点仍能提示缺项。
6. **返回原会话使旧确认复活**：提交同时校验来源会话与预览版本；S→B→S之后旧确认保持失效，预填和复制均受保护。

客户端独立测试另发现旧helper调用未提供instances且路径无选中项时，slice(0,-1)误报缺项；已加last>0边界并通过全量回归。

定向复核确认上述修复成立；模拟浏览器存储配额失败时，宿主仅预填一次，显示保存警告并关闭确认，不进入重复创建流程。

## 已知限制与后续验证

- 真实模型是否给出有用路径、是否正确发现问题及实际收费未验证；新提示生效需用户重启本地宿主。再次生成由用户预览确认，不自动重做旧报告。
- 旧报告无明确paths时没有整链，不按类别或语义猜测真实路线；新报告也允许省略路径。
- 所有节点与状态都是AI摘要/标注，原文必须另查；关系并不证明错误根因。不能直接看到模型内部思考。
- 派生快照仅在本浏览器localStorage，最多20份、500000个UTF-16单位；超限淘汰最早记录，不同步桌面/网页，不是永久备份。画布最多显示最近3份，其余可从左栏查看。
- 预填/复制只创建材料快照，不记录宿主目标会话ID，不追踪后续会话，没有原生fork或真正的会话分支合并。
- 未确认选择仅模块内缓存6份，完整刷新重置；已确认快照可恢复选材。没有自由编辑AI路径、修改摘要、地图搜索或文字阅读替代。
- 图大时需平移/缩放；完整键盘、屏幕阅读器、高DPI、原生桌面矩阵仍待验证。不能把隔离浏览器通过写成所有桌面环境通过。
