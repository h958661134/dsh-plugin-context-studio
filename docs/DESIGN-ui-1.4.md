# v1.4 上下文调试：交互与视觉方案

## 判断

现有真实截图 `docs/images/modular-overview.jpg` 的主要问题是：项目、会话、页签、标题重复占据空间；来源分类卡片回答“有什么”，但没有回答“这一步发生了什么”。新界面以一条回答路径为中心，收起素材管理，直接支持核对与重开分支。

## 落地布局

- 顶栏只有“上下文调试”、当前项目/会话选择、刷新与次要操作记录入口。没有脉络/素材墙页签，也不再发出 graph/pieces 扫描请求。
- 顶部回答时间轨道：短回答节点按真实时间顺序连接，当前回答显著，前后/首末/整组跳转保留；回答预览控制两行。目录读取与详情失败相互独立。
- 中心是带明确连接线的数据流画布：左列为日志中的上次回答、引用和来源锚点；中间为本页真实上下文节点，默认强调这步新增和被替换内容；右列为当前回答。存在精确请求边时，将工具调用作为中间的小锚点单独排布，使 `33 → 34 → 35 → 39` 从左向右读完。节点连线只取 inspect-flow 返回的 edges，不猜测模型因果。线型和文字分别标明请求调用、输入包含、调用结果、引用快照、来源和替换关系；同端点的不同语义边平行错开。
- “沿用 N 条”默认折叠成摘要，点击切换全部输入。主筛选按变化而非分类：这步变化 / 全部输入 / 已替换 / 待核对 / 位置未知；来源类别只作节点小标签。每页最多12条，图下明确分页与关系省略提示。
- 右侧固定工作侧栏：上方“排查”显示具体 guidance，点线索以 scope+focus 定位到正确记录页；下方“新分支”显示所选上下文，支持排序、任务、目标项目、预览和创建。分支是精选内容填入 startSession 草稿，确认后才执行，不复制整段历史、不自动发送。
- 点图节点打开原文抽屉，保留正文/参数分页、选择文字、绝对偏移来源和去重。抽屉标明来自哪条路径，加入后显示已选状态；右侧草稿随即可见。
- 历史操作记录与备份撤销留在次要抽屉，撤销仍需确认。新主界面不暴露文件清理或写入指令入口。

## 视觉

中性灰背景、深灰文字与低饱和蓝绿强调；新增用蓝绿，替换用柔和琥珀，未知用虚线。保留清楚的节点标题和可读预览，减少小字与重复边框。主要操作使用文字按钮，图中央留出线缆空间；窄屏将侧栏下移，画布可横向滚动，不挤压节点文字。图不使用装饰性假边，页外锚点明确弱化为“来源”。

少节点画布最低约 270px，随本页节点数量增高并受滚动容器限制，避免用空白撑满首屏。排查说明限制可见行数，完整内容仍在节点文案中。顶部固定保留“准备分支草稿 · N”入口，侧栏下部被滚动遮挡时仍可进入确认流程。空白会话的待输出锚点写“尚无输出”，不标为外部会话。

## 契约与验证

接口使用 `/inspect-flow` 的 `scope/page/focus/module`、真实 `nodes/anchors/edges`、`comparison/guidance` 和分页时间轨道；原文继续使用 `/inspect-detail`。超出结构容量时保留回答导航并显示数量未知，不能把未读取的数据当零；无回答时省略 answer，不把 boundary 当回答序号。

默认会话已接入经过主代理源码核实的 `ctx.get('uiSession')?.adapter?.current`：插件 apply 生命周期即读取 `getSnapshot()?.key` 并注册 `subscribe(listener)`。进入插件后 mainView 消失时保留本次运行最近观察到的 ID，只称“刚才查看的会话”；组件手动选择优先，后来的订阅通知不会抢选。服务缺失或读取异常时回退到会话目录；插件释放时注销订阅。不读取 uiWorkspace 私有字段，也不声称掌握完整浏览历史。

本版仅支持精选片段生成新分支草稿，未加入原生 atSeq 历史克隆分叉。启动仍通过 `uiWorkspace.startSession`，用户确认追加/替换后预填，不自动发送。

客户端 VM 回归继续覆盖超时、取消、防迟到、空回答、未知容量、翻页选择、source/arguments/offset 去重、失败重试、存储恢复、复制新正文和启动确认。新增校验图的所有边均来自接口、节点按真实关系可访问、guidance 定位及旧页签不扫描。浏览器与截图由主代理在隔离环境验收。

最终客户端测试：`node --test tests/client.test.mjs tests/client-modules.test.mjs` **37/37 通过**；`node --check lib/client.js` 通过。原有关键可靠性场景全部保留，分类卡片场景迁移为范围、线索与真实图节点交互，并加入完整 FlowGraph 渲染、请求调用链、同端点边错开、当前会话跟随、旧偏好不扫描、启动确认及备份撤销测试。

主代理反馈的真实验收：当前会话跟随到回答 #39；线索定位用户要求 #9；较早回答 #21 不含未来工具内容；结果 #35 所选 7 字加入与重复去重成功；确认 replace 后仅预填已有 3 个片段，未发送。900×800 窗口主容器无横向溢出，原文抽屉宽度受控，图内部可横向滚动。本分工未操作真实浏览器，这些观察与 `flow-*` 截图由主代理提供。

仍有明确边界：画布只呈现当前页及有上限的关系锚点；省略关联数直接展示。连线说明日志关系，不能确定模型内部注意力或错误因果。默认会话仅来自插件运行期间观察到的公开宿主值。未修改后端、README、运行环境，也未创建提交。
